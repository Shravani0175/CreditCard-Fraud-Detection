# Credit Card Fraud Detection

## About
A machine learning project that identifies potentially fraudulent credit card transactions using classification algorithms.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
- Logistic Regression
- Random Forest Classifier

## Project Workflow
1. Data loading and exploration
2. Data preprocessing
3. Feature scaling
4. Train-test splitting
5. Model training
6. Model evaluation
7. Model comparison

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Dataset
[Credit Card Fraud Detection Dataset – Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

## How to Run
1. Clone this repository.
2. Install the required libraries.
3. Download the dataset from Kaggle.
4. Place `creditcard.csv` in the project folder.
5. Open the Jupyter Notebook and run the cells.
